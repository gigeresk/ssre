## psnr.py
A simple command line tool to compare the peak signal-to-noise ratio of two images.
Use on the original frame and the super-resolved frame to compare loss

### Example Usage:
`python3 psnr.py -o <input.jpg> -m <output.jpg>`

## to_torchscript.py
Essentially, we take a model (.pth) generated by super_resolve.py and trace its output using an inputted image.  The output is a TorchScript (C++-ready) model (possibly) named traced-script-module.pt
TODO this has a bit of a weird structure and it has code duplication from super_resolve.py, as we learn more about TorchScript we should fix this up
